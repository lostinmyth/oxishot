# oxishot

oxishot is an app for editing the screenshots you take. Grab a screenshot, open it in oxishot, and make it presentable in a few seconds: crop it, annotate it with arrows, boxes, and text, blur or redact anything sensitive, and add some polish like padding, backgrounds, and rounded corners before you share it.

The goal is to keep it fast and out of your way. There's no heavy image editor to learn, just the handful of tools you actually reach for when you're about to paste a screenshot into a chat, a doc, or a bug report. The project is in early development, so expect things to change.
